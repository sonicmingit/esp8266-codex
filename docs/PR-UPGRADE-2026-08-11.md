# PR 升级集成说明（2026-08-11）

本分支基于上游 `v0.4.11`（`0096775`），构建标识为 `0.4.11-u1`。
目标是保留“Claude Code / Codex 额度桌面屏”定位，合并低风险、可独立验证的修复与增强。

## 已集成

- PR #2：Windows 日志按文件 mtime 缓存，避免每 5 秒重扫当天全部 Claude 日志。Mac 部分由更完整的 PR #21 实现替代。
- PR #10：Mac 纯有线模式通过 `#CMD` 发送显示/亮度命令，并处理短写失败。
- PR #11：新增可选 `MODE_DUAL` 双栏额度页；保留 v0.4.11 的周额度重置提示，并补齐 Windows 托盘入口与镜像渲染。
- PR #16：Windows 可选择绑定网卡，设备发现、桥接监听、请求源地址和网速统计使用同一网卡。
- PR #19：Mac/Windows 桥接端口可配置，监听失败会给用户可见提示。
- PR #21：Mac 状态日志改为后台增量扫描，避免菜单弹窗阻塞主线程；并发回调和日志截断有回归测试。

## 暂不集成

- PR #13：已关闭，且大部分有线能力与现有串口回退及 PR #10 重叠；其 wired-only 固件仍缺音乐封面、自定义 GIF、网页和亮度持久化。
- PR #14：已关闭，仅修复 Mac 菜单栏图标明暗适配，不影响额度查询、固件或 Windows 客户端。
- PR #15：把产品扩展到天气、壁纸和 DeepSeek，改动约 2,885 行且与 v0.4.11 / PR #11 的 `main.cpp` 大面积冲突；没有 Windows 对等实现，不适合并入本次稳定升级。

## 构建验证

- Windows：.NET SDK 8.0.423，`dotnet build -c Release` 成功，0 警告、0 错误。
- 固件：PlatformIO 6.1.18、Espressif8266 4.2.1、Arduino ESP8266 3.1.2；RAM 44,236 / 81,920（54.0%），Flash 878,915 / 1,044,464（84.1%）。
- 双栏页：运行 `tools/sim/test_states.py`，覆盖未知值、100%→5%、长倒计时→45m、working/idle 翻转和 0% 场景，无残影。

## 尚未验证

- 未刷入真实 SD2，屏幕色序、抗锯齿字体、启动稳定性和串口行为仍需实机确认。
- 当前 Windows 主机不能运行 Swift/macOS 测试；PR #21 的 Mac 编译和测试结论来自该 PR 的作者验证。
- Windows 托盘交互、多网卡切换和端口占用弹窗已通过编译，但仍建议在目标 Windows 机器上做一次运行验证。
