# v0.4.7-sonic · Wi-Fi 自动重连

本次更新 ESP8266 / SD2 固件，解决设备比路由器先启动时停留在配网热点、无法主动连接已保存 Wi-Fi 的问题。

## 更新内容

- **自动重连**：开机连接失败或运行中断网后，按设定间隔重试已保存的网络，默认 **5 分钟**。
- **网页设置**：在配网热点首页进入「WiFi 重连设置」，或在设备联网后的管理网页修改间隔；支持 **30～86400 秒**，300 秒为 5 分钟，重启后保留。
- **配网期间暂停**：手机等设备连接配网热点时暂停自动重试；如果重试已开始则停止该次尝试，最后一个设备离开热点后重新计时。自动连接成功后关闭热点并启用设备管理网页。
- **USB 模式**：保留「USB 直连时关闭设备 Wi-Fi」选项；该选项生效时不进行 Wi-Fi 重试，并保留已保存的网络信息。
